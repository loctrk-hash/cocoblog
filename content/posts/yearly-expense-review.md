月是記帳的單位，年才是生活的單位。很多變化在單月裡看起來像雜訊，拉到 12 個月才會浮出來：某個類別慢慢墊高、每年固定出現的兩筆大額、以為省了其實只是換了月份。年底到了，與其急著訂明年的宏大目標，不如先問：這一年我的錢到底怎麼流動？

年度回顧不是把 12 個月的數字加起來然後感嘆。它要回答三個問題：**總共花多少、錢花去哪、什麼東西在變**。答案最後只要變成明年的一件事就夠。

<!--more-->

## 年度回顧看三件事，不是看總額

多數人一打開年度統計，先盯總支出。總額很重要，但它只是結果。同樣一年花 60 萬元，可能是每月穩定 5 萬，也可能是 10 個月各 4 萬、2 個月各 10 萬；背後的行動完全不同。

所以先看三層：

1. **總額**：這一年進出多少。
2. **結構**：錢集中在哪些類別。
3. **變化**：哪些東西在變多、變少，或定期出現。

總額告訴你「多少」，結構告訴你「哪裡」，變化才告訴你「該做什麼」。

## 先算三個年度數字

不論用試算表或 App，先記下三個數字：

| 數字 | 怎麼算 | 用途 |
|---|---|---|
| 年度總支出 | 12 個月的支出加總 | 知道基本盤 |
| 年度總收入 | 12 個月的收入加總 | 知道資源 |
| 收支差額 | 總收入 − 總支出 | 知道這一年是留存還是透支 |

有幾個提醒：

- **還沒結束的月份先不要算進去**。現在是 11 月，今年先用到 10 月為止；要跟去年比，就用去年完整的 12 個月。拿 11 個月跟 12 個月比，會以為自己變省了。
- **年終、獎金或退稅要標註**。這些不是每月都有的常態收入，別把它平均分到每個月。
- **沒記的月份要處理**。中間有幾個月完全沒記，先補記或直接排除，不要混著算。

## 一次性大額先看，別讓它扭曲全年

年度資料最容易被誤讀的，是那幾筆一年只出現一次的大錢：年繳保費、牌照稅、所得稅、旅行、家電維修、婚喪喜慶。

這些錢不是「不正常」，只是不按月發生。問題是，它們會讓某幾個月看起來特別超支，進而誤導你以為生活費失控。

做法很簡單：把一次性大額挑出來，除以 12，攤回每個月。例如年繳保費 18,000，等於每月 1,500；牌照稅與燃料費 6,000，等於每月 500。攤完之後再看月度數字，才會接近真實負擔。這套做法在[固定支出 vs 變動支出](/posts/fixed-vs-variable-expenses/)已經說明過，年度回顧只是把它用在大尺度上。

攤提有三個好處：

- 預算不會在繳費月爆掉。
- 比較月份時不會被單筆大額帶偏。
- 明年一開始就能先留錢，不用事後補洞。

## 慢性成長比單月暴增更值得注意

單月暴增通常有故事：旅行、維修、一次購物。它的問題是偶發，查清楚就好。真正會把預算慢慢吃掉的是慢性成長。

慢性成長的樣子是：同一個類別連續三、四個月都比前一個月高一點，每月看都不嚴重，一年下來卻多了好幾千。

最常見的來源：

- 外送從一週一次變成一週三次。
- 訂閱服務項目默默增加，每個月多幾十到幾百。
- 通勤票價調整，或搬家後交通距離變長。
- 孩子、寵物或健康相關支出慢慢增加。

找這種變化，用月度榜單沒用，要看同一類別的走勢。用 CocoBook 的人，可以直接看[歷史走勢圖](/posts/history-trend-chart/)；手上有 12 個月資料的人，也可以用試算表拉一張折線。重點不是工具，而是把時間軸拉開。

判斷口訣：**尖峰查事件，斜坡查習慣。**

## 季節性還是習慣性，差在會不會自己消失

有些支出每年都會出現，但不等於壞習慣：暑假旅行、年底聚餐、過年送禮、夏季電費。這些是季節性支出。

季節性支出的特徵是：時間點相近、每年都來、過了就消失。對付它的方法不是節儉，而是提前幾個月預留。

習慣性支出則是：沒有明顯季節、每月都在、金額慢慢上升。對付它的方法才是改頻率或設上限——就像[小額高頻支出](/posts/small-frequent-spending/)說的，改次數比改金額有效。

兩者混淆，就會出現「明明已經很省，卻還是覺得緊」的感覺：你砍掉的是季節性的享受，真正上升的習慣性支出還在。

## 三張表格，把一年整理完

不需要複雜模型，三張表就夠。

### 表一：年度總表

| 項目 | 今年 | 去年 | 差異 |
|---|---:|---:|---:|
| 總收入 |  |  |  |
| 總支出 |  |  |  |
| 收支差額 |  |  |  |
| 一次性大額合計 |  |  |  |
| 攤提後每月基本支出 |  |  |  |

如果沒有去年資料，就先填今年，差異欄留空。明年回來看，就是最好的起點。

### 表二：類別占比

| 類別 | 年度金額 | 占比 | 比去年同期 |
|---|---:|---:|---:|
| 飲食 |  |  |  |
| 居家 |  |  |  |
| 交通 |  |  |  |
| 學習 |  |  |  |
| 娛樂 |  |  |  |

看占比時別急著把最高的一類當成問題。占比高可能只是收入低或家庭結構不同；要對照的是「它有沒有變高」。

### 表三：月份異常清單

| 月份 | 異常事件 | 一次性嗎 | 後續行動 |
|---|---|---|---|
| 2 月 | 年繳保費 18,000 | 是 | 改成每月提撥 1,500 |
| 8 月 | 旅行 25,000 | 是 | 明年 5 月開始存 |
| 9～11 月 | 外送逐月增加 | 否 | 改成一週兩次 |

這張表是年度回顧最重要的產出。前兩張表在描述事實，這張表才開始把事實變成行動。

## 把結論變成明年的一件事

很多人做完年度回顧，會寫下十幾個改善項目：要存錢、要少外食、要取消訂閱、要記帳更勤。結果明年二月就全部放棄。

只選一件事。挑選標準有三個：

1. **它在資料裡重複出現**，不是單月情緒。
2. **它能用一個動作描述**，例如「外送一週最多兩次」。
3. **它有檢查點**，例如「每個月 1 號看上個月的次數」。

把這件事寫進明年的預算或行事曆，而不是只放在心得裡。需要設金額上限的人，可以接著看[每月預算怎麼設](/posts/monthly-budget-setup/)；想看單月怎麼拆，則可以看[月報表解讀](/posts/monthly-report/)。

## 五個常見錯誤

- **拿未滿月比較**：還沒結束的月份一定偏低，先排除。
- **忽略年繳**：它會讓特定月份假性超支，先攤提再判斷。
- **只看總額**：總額不變，結構可能已經換過一輪。
- **一次改太多**：同時改五個習慣，通常五個都留不住。
- **拿特殊年份當常態**：失業、搬家、生病、結婚那一年不適合當基準。

## 今天就能做的一件事

翻出今年（先到 10 月）或去年完整 12 個月的紀錄，先做兩步：

1. 圈出金額最高的三筆一次性支出，把它們除以 12。
2. 找出一個連續三個月上升的類別，寫下它大概增加了多少。

不用寫完整年度報告。這兩步做完，你已經有了明年第一個該處理的對象。

年度回顧的目的不是責備過去的自己，而是把混亂的一年整理成一條線索。線索夠清楚，明年才知道要改哪裡。
