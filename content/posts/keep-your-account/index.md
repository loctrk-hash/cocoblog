CocoBook 記帳（網頁版）可以用訪客帳號直接開始，不必先註冊或綁定任何東西。方便歸方便，登入頁自己就寫著提醒：**瀏覽器清空快取或換手機時，可能造成登入帳號遺失**。

帳號一不見，原本記下來的內容就帶不過去。與其到那天才後悔，不如現在花一分鐘處理。這篇把畫面上提供的兩條路拆開：保存訪客帳號，或改用 LINE 登入。

**截圖中的帳號與數字都是示範資料，不是真實資料。**

<!--more-->

## 先看現在是哪一種狀態

登入後，主畫面頂端會顯示目前的帳號資訊：如果用訪客身份登入，會看到「訪客帳號」字樣；如果用 LINE 登入，則會顯示 LINE 名稱。旁邊還有「綁定 LINE」與「登出」。

{{< figure src="04-main-guest.png" alt="主畫面頂端顯示訪客帳號、綁定 LINE 與登出" caption="圖 1：頂端顯示「訪客帳號」時，代表目前是訪客身份。（畫面為示範資料）" >}}

先用這個位置判斷自己屬於哪一種，再決定要做什麼。

## 訪客帳號的方便與風險

登入頁把優缺點都寫得很清楚：**優點**是不須綁定任何帳號，直接建立一個訪客帳號就能登入系統；**缺點**是清空快取或換手機時，可能讓登入帳號遺失，可以透過保留登入帳號或綁定 LINE 避免。

{{< figure src="01-login-guest.png" alt="登入頁顯示訪客帳號的優點與缺點說明" caption="圖 2：登入頁自己就提醒了帳號遺失的風險。（畫面為示範資料）" >}}

畫面上那串 `guest_` 開頭的字元，就是讓你回到同一個帳本的關鍵。它不像密碼可以重設，也不像電子郵件可以找回——**一旦遺失，就無法找回原本紀錄**。

## 方法一：把訪客帳號存進文檔

### 步驟 1：顯示現行的訪客帳號

在登入頁按「顯示現行的訪客帳號」，會出現「訪客帳號」視窗，裡面有一整串 `guest_` 開頭的字串，並提醒你複製保存。

{{< figure src="02-guest-account-dialog.png" alt="訪客帳號視窗顯示 guest 開頭的帳號字串與保存提醒" caption="圖 3：視窗直接提醒「請複製保存，清空快取或換手機時可用回復訪客帳號找回」。（畫面為示範資料）" >}}

### 步驟 2：複製並存到不會被清掉的地方

把整串字複製起來，貼到文檔、備忘錄或筆記軟體裡，並取一個認得出來的名稱，例如「CocoBook 帳號」。

重點是**不要只留在瀏覽器裡**：分頁、書籤、自動填入都可能跟著快取一起消失。存到獨立的文檔，才算真的保存。

不同帳號會有不同的 `guest_` 字串。下圖是另一組訪客帳號的登入頁，可以看出字串並不相同。

{{< figure src="05-login-another-guest.png" alt="另一組 guest 開頭的訪客帳號登入頁" caption="圖 4：不同訪客帳號對應不同的 guest_ 字串，要存的是你正在用的那一組。（畫面為示範資料）" >}}

登入頁另外還有「改變訪客帳號」按鈕，用來切換到其他訪客帳號。一般保存流程不需要按它；如果你現在是在別的帳號上，先確認畫面顯示的是原本要保留的那串字，再複製。

{{< figure src="03-login-change-account.png" alt="登入頁上可見改變訪客帳號按鈕" caption="圖 5：「改變訪客帳號」是切換帳號的入口，不是保存帳號的步驟。（畫面為示範資料）" >}}

### 步驟 3：換機或清快取後貼回去

之後在登入頁按「回復訪客帳號」，畫面會要求你填入之前保留的訪客帳號。

{{< figure src="06-restore-dialog.png" alt="回復訪客帳號視窗要求填入之前保留的帳號字串" caption="圖 6：把事先存好的 guest_ 字串貼進這裡。（畫面為示範資料）" >}}

貼上並送出後，回到主畫面，原本的紀錄與統計就會出現。

{{< figure src="07-restored-main.png" alt="回復後主畫面顯示原本的本月結餘與收支數字" caption="圖 7：回復成功後，原本的紀錄與本月統計都回來了。（畫面為示範資料）" >}}

## 方法二：綁定 LINE 登入

不想自己保管那串字的人，可以在主畫面頂端按「綁定 LINE」。

{{< figure src="08-bind-line-entry.png" alt="主畫面頂端的綁定 LINE 入口" caption="圖 8：主畫面頂端可以選擇綁定 LINE。（畫面為示範資料）" >}}

完成後，日後改用 LINE 登入。登入後頂端的名字會變成你的 LINE 名稱，旁邊一樣有到期日與登出。

{{< figure src="09-line-login.png" alt="用 LINE 登入後，主畫面頂端顯示 LINE 名稱 darius" caption="圖 9：用 LINE 登入後，頂端顯示的是 LINE 名稱。（畫面為示範資料）" >}}

這裡有一個重要的限制：**綁定之後，以後只能用 LINE 登入**。所以綁定前先確認這個 LINE 帳號是你會持續使用的；不要預期還能靠原本的 guest_ 字串進去。

## 兩種方式怎麼選

| 項目 | 保存訪客帳號 | 綁定 LINE |
|---|---|---|
| 要不要自己記一組字串 | 要，guest_ 開頭 | 不用 |
| 換機或清快取後 | 用「回復訪客帳號」貼回去 | 用 LINE 登入 |
| 主要風險 | 字串不見就無法找回原本紀錄 | 綁定後只能用 LINE 登入 |
| 適合誰 | 想維持訪客身份、不想綁定任何東西 | 本來就固定用 LINE、不想保管字串 |

不論選哪一種，都比「什麼都不做」安全。差別只在於你要保管的是一串字，還是依賴一個你已經常用的帳號。

## 常見問題

**只把分頁留著算保存嗎？** 不算。清空快取或換手機時，分頁與瀏覽器資料可能一起消失，還是要把 guest_ 字串存到獨立文檔。

**已經換手機才發現沒保存怎麼辦？** 如果備忘錄或舊裝置裡還找得到 guest_ 字串，就用「回復訪客帳號」貼回；如果連字串都沒有，就無法找回原本紀錄，只能重新建立一個帳號。

**綁定 LINE 之後還能用訪客帳號登入嗎？** 不能。畫面限制只能用 LINE 登入，所以綁定前要確定你會持續使用那個 LINE 帳號。

## 今天先做的一件事

打開 CocoBook 記帳（網頁版），看主畫面頂端。如果顯示「訪客帳號」，就按「顯示現行的訪客帳號」，把 guest_ 字串複製到文檔存好；如果你確定固定用 LINE，就按「綁定 LINE」。

動作不到一分鐘，但換手機那天會省很多功夫。想回頭看整體功能，可以參考[CocoBook 記帳功能總覽](/posts/cocobook-getting-started/)。
